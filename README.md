# 깃 협업 가이드

깃과 깃허브로 협업하는 과정을 안내하는 웹페이지입니다. WAP의 프로젝트를 시작하는 팀장과 팀원을 대상으로 저장소 준비부터 이슈 작성, 개발, 코드 리뷰와 병합까지의 흐름을 다룹니다. 깃허브 데스크톱과 깃허브 웹 화면을 중심으로 설명합니다.

[가이드 바로가기](https://pknu-wap.github.io/git-guide/)

## 다루는 내용

### 1. 시작하기

| 가이드                        | 배울 내용                                              |
| ----------------------------- | ------------------------------------------------------ |
| (팀장) 팀의 레포지토리 만들기 | pknu-wap 조직에 저장소를 생성하고 팀원을 초대하는 과정 |
| 팀의 레포지토리 복제하기      | 깃허브 데스크톱으로 저장소를 내 컴퓨터에 복제하는 과정 |

### 2. 개발하기

| 가이드                | 배울 내용                                                                      |
| --------------------- | ------------------------------------------------------------------------------ |
| Git으로 함께 개발하기 | 깃과 깃허브의 차이, 이슈 작성, Pull, 브랜치, 커밋, 푸시, PR과 머지의 기본 흐름 |
| GitLab Flow 이해하기  | feat와 main, production을 이용해 개발, 리뷰, 배포를 연결하는 브랜치 전략       |
| PR 리뷰 주고받기      | PR 준비, 리뷰어 지정과 CODEOWNERS, 피드백 반영, 승인과 머지 과정               |

### 3. 더 알아보기

| 가이드               | 배울 내용                                                                                  |
| -------------------- | ------------------------------------------------------------------------------------------ |
| 충돌 해결하기        | 충돌이 발생했을 때 깃허브 웹 또는 vscode로 해결하는 방법                                   |
| 실수한 작업 취소하기 | 커밋과 푸시 여부에 따른 Discard changes, Undo Commit, Revert, Reorder + Undo, Reset의 사용 |
| GitHub CLI 사용하기  | gh 설치와 이슈·PR 활용 예시, IDE 내장 터미널 사용                                          |
