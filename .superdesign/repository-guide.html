CHAPTER 1

팀의 첫 저장소 만들기

대상: 팀장 소요 시간: 약 5분

저장소(Repository)는 팀의 코드와 변경 이력이 담기는 공동의 집입니다. 팀장은 프로젝트 시작 시 저장소를 한 번 생성하고, 생성된 URL을 팀원들에게 공유합니다.

시작 전 준비사항

GitHub 로그인이 완료되어 있어야 하며, pknu-wap 조직 내에서 저장소 생성 권한이 필요합니다. github.com/new에 접속하여 시작하세요.

1

기본 정보 설정 (General)

  • • Owner: 반드시 pknu-wap 조직을 선택해야 합니다.
  • • Repository Name: 팀별로 고유한 이름을 정하세요 (예: waps-server).
  • • Description: 프로젝트의 성격을 간단히 기술합니다 (예: 2026년 2학기 웹3팀 WAPs 서버).
2

환경 설정 (Configuration)

  • • Visibility: 이미지에서는 Public을 선택했습니다. 누구나 볼 수 있으며, 쓰기에는 권한이 필요합니다. 팀의 공개 정책에 따라 Private을 선택할 수도 있습니다.
  • • Template: pknu-wap/project-template을 선택하여 초기 구조를 가져옵니다.
  • • Include all branches: 이미지처럼 On을 켜면 모든 템플릿 브랜치를 가져옵니다. 복사된 브랜치끼리는 이력이 연결되지 않아 서로 병합하거나 PR을 만들 수 없습니다.
3

저장소 생성 완료

조직, 팀의 저장소 이름과 설정을 확인한 후 Create repository 버튼을 누릅니다. 생성된 저장소에 템플릿 파일과 브랜치가 있는지 확인하고 URL을 팀원에게 공유하세요.

주의: 저장소 생성 직후에는 팀원들에게 쓰기 권한이 자동으로 부여되지 않을 수 있습니다. 조직 관리 설정을 확인하세요.
