## Exact lesson content
Repository means shared home for code and change history. Team leader creates it once, then shares the URL. Prerequisites: GitHub login and repository creation permission in pknu-wap. Open https://github.com/new . If template is not listed, open https://github.com/pknu-wap/project-template and Use this template → Create a new repository.
1. General: Owner pknu-wap (team organization, requires permission), Repository name waps-server is an example, choose team-specific unique name. Description example 2026년 2학기 웹3팀 WAPs 서버입니다.
2. Configuration: Choose visibility Public as screenshot; everyone can view, writing still needs permission. Use Private if team requires restricted visibility. Start with a template pknu-wap/project-template. Include all branches On, as shown; copies all template branches. Do not claim this is universally mandatory. Note template branches have unrelated histories, so cannot merge or create PRs between those copied branches.
3. Create repository button; verify name and owner before clicking. Once created, confirm template files and branches exist and share repository URL with teammates. Creation does not automatically grant teammates write access.
Checklist: organization/name confirmed; visibility checked; correct template and branch option checked; created repository files checked.
Source links in a quiet footer: https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository and https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-repository-from-a-template .
